# Python-PyTorch-Course

Notebook-first course materials for learning PyTorch—from tensor fundamentals and autograd, through training loops and data pipelines, to vision/audio/NLP workflows, performance, distributed training, and deployment.

This repo contains:
- A **single “all-in-one” notebook** with every chapter concatenated.
- A **chaptered notebook folder** for modular learning.

---

## Repository layout

- **`PyTorch Course Complete.ipynb`**
  - The full course in one notebook (expanded edition).
  - Generated: **2026-01-25** (per notebook header).
- **`PyTorch Course Notebooks/`**
  - The same material split into per-chapter notebooks.

---

## Prerequisites

- Python 3.10+ recommended
- JupyterLab / Jupyter Notebook
- PyTorch (CPU, CUDA, or Apple Silicon MPS)

Optional (recommended for transformer/NLP chapters):
- `transformers`, `datasets`, `tokenizers`, `accelerate`, `evaluate`
